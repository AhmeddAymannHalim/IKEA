ASP.NET Core MVC Application
A comprehensive ASP.NET Core MVC Application developed from scratch, implementing core functionalities such as user authentication, role-based authorization, and a custom security module. The application adheres to modern best practices and focuses on clean, maintainable code.

Features
Custom Security Module: Implemented user authentication, password hashing, and role-based access control without external libraries.
Fully Functional MVC Application: Includes models, views, and controllers built from scratch.
Responsive UI: Designed with Bootstrap for modern and responsive layouts.
Database Integration: Uses SQL Server with Entity Framework Core for seamless data management.
Validation: Implements both client-side and server-side validation.
Error Handling: Centralized error handling and custom middleware for exceptions.

Tech Stack
Framework: ASP.NET Core 8.0 (MVC)
Database: SQL Server with Entity Framework Core
UI Framework: Bootstrap 5, HTML5, CSS3
Authentication: Custom-built security module for login, registration, and roles
Languages: C#, Razor Pages
